# Demonstration Evidence

This folder holds Final Project demonstration evidence. It is empty for this Midterm
submission, which covers only the completed Computer Vision (SEE -> RECOGNIZE) stage.

**Planned for the Final project:** once the 4WD chassis, motor driver, and decision logic
described in the main `README.md` and `src/robot/` are built, this folder will hold:

- Photographs of the completed robot/system.
- Screenshots and recordings of Computer Vision outputs during autonomous operation.
- Video Demonstration, Test 1: Figure-8 Line Detection and Tracking.
- Video Demonstration, Test 2: Group Project Specialization (Object Sorting), showing the
  robot identifying a waste item and moving it to the matching category.
- Evidence of the complete SEE -> DECIDE -> ACT process (recognized class leading to a motor
  action).
- Relevant final testing results.

See `results/test_1/` and `results/test_2/` for where the corresponding test result files will
live, also planned for the Final project.
